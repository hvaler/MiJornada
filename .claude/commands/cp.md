# ⚡ CP - Checkpoint Rápido

## Contexto
Guardado mínimo cuando hay muy poco tiempo. Solo copia un template.

## Ejecución INSTANTÁNEA

### Output Inmediato

```
⚡ CHECKPOINT

Copia este texto antes de cerrar:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

RECUPERAR_[FECHA]:
- Evolutivo: [EVO-XXX detectado o "ninguno"]
- Haciendo: [última acción visible]
- Archivos: [archivos mencionados recientemente]
- Próximo: [siguiente paso lógico]

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Pega esto en /recuperar cuando vuelvas.
```

### Nota
Este comando NO escribe archivos - solo genera texto para copiar.
Es el más rápido posible para emergencias extremas.
