# Recursos para Analisis de Arquitectura

> **Este NO es un skill invocable.** Es una carpeta de recursos (prompts, plantillas, checklists)
> que el comando `/analisis-arquitectura` lee directamente.
>
> Para ejecutar un analisis arquitectonico, usar: `/analisis-arquitectura`

---

## Contenido de esta carpeta

### Prompts (instrucciones de analisis)

| Archivo | Uso |
|---------|-----|
| `prompts/prompt-clean-architecture.md` | Secciones obligatorias para proyectos CA |
| `prompts/prompt-general.md` | Secciones obligatorias para proyectos sin CA + migracion |

### Plantillas (formato de salida)

| Archivo | Uso |
|---------|-----|
| `templates/ANALISIS_ARQUITECTURA.md.template` | Estructura del documento Markdown |
| `templates/ANALISIS_ARQUITECTURA.html.template` | HTML profesional con sidebar, dark mode, Mermaid |

### Checklists

| Archivo | Uso |
|---------|-----|
| `checklists/clean-architecture.md` | Cumplimiento Clean Architecture |
| `checklists/migration-viability.md` | Viabilidad de migracion a CA |
| `checklists/api-design-review.md` | Revision de APIs REST |
| `checklists/database-review.md` | Revision de BD |
| `checklists/performance-review.md` | Revision de rendimiento |
| `checklists/security-review.md` | Revision de seguridad (OWASP) |

### Patrones

| Archivo | Uso |
|---------|-----|
| `patterns/design-pattern-catalog.md` | Catalogo de patrones y anti-patrones |
| `patterns/dependency-analysis.md` | Analisis de dependencias NuGet |
